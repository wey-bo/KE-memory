# Research Workspaces

This directory holds non-runtime research and migration workspaces. The installable memory system remains split across src, service, and ontology.

next-prep is a normalized snapshot of the H100 preparation workspace used to develop representation-neutral memory contracts, extraction diagnostics, identity and membership gates, QuerySlotPlan work, and ontology-linking admission prototypes.

Do not use eval for migrated research snapshots. eval is reserved for future automatic evaluation logic, runners, scorers, and stable fixtures after the runtime flow is ready.
