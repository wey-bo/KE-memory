# 已作废的外部 NL2KE 历史提案

本目录中的 [`nl2ke-service-proposal.md`](nl2ke-service-proposal.md) 是外部提供方曾提交的原始历史提案，仅用于审计和追溯。它不是 `memory-assertion/v1` 的活动合同，也不得作为实现或验收依据。

唯一活动的 NL2KE 接口合同是 [`NL2KE 对接要求`](../../../../specifications/memory-assertion-v1/nl2ke-integration-requirements.md) 中的 `POST /v1/compile` 及其同一交换 Schema。禁止继续采用历史提案中的 `POST /v1/ke`、请求内联 ontology、可关闭最终验证或其他与活动合同冲突的约定。
